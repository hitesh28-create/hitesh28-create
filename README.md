# 🛒 Dmart Grocery Sales Analysis & Future Sales Prediction
## 📌 Project Overview

This project analyzes historical grocery sales data and builds a Machine Learning model to predict future sales and profit. The system helps uncover business insights, identify profit-driving factors, and support data-driven retail decision-making.

---
## Objectives

- Perform Exploratory Data Analysis (EDA) to understand trends and seasonality

- Identify key features influencing sales and profit

- Build a Machine Learning model for future sales prediction

- Visualize insights through charts and dashboards

--- 
## Dataset Description

The dataset contains retail grocery sales records with features such as:
- Product Category & Sub-category

- Order Date (Year & Month extracted)

- Sales

- Profit

- Discount

---
## Data Preprocessing
- Handled missing values

- Extracted Year and Month from order date

- Encoded categorical features

- Cleaned and formatted data for model training

---
## Exploratory Data Analysis (EDA)

EDA helped uncover patterns and trends in the business:

- Category-wise and sub-category-wise performance

- Monthly and yearly sales trends

- Correlation analysis between sales, profit, and discount
---

## Machine Learning Model

**Model Used**: Random Forest Regression

### Why Random Forest?

- Works well with mixed data types

- Reduces overfitting

- Provides strong prediction accuracy with minimal tuning

### Target Variables:

- Sales

- Profit

--- 

## Future Forecasting

The trained model can predict future sales and profit based on historical patterns, helping businesses make informed inventory and marketing decisions.
